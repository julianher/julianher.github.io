This Portfolio Site.

No template, no framework, no page builder. The site you are reading was designed with Claude, built with Claude Code, and shipped to GitHub Pages. It is as much a prompt-engineering exercise as a design one.

Type Personal portfolio site
Stack HTML · CSS · vanilla JS
Hosting GitHub Pages
01Overview

You are looking at it.

There is no Squarespace template or heavy framework behind this page. Every screen is hand-written HTML, one shared stylesheet, and a little vanilla JavaScript, wrapped in a warm "document" aesthetic, a paper palette with a terracotta accent and Source Serif type, that was designed together with Claude before any CSS existed.

The real work was not typing the code. It was prompt engineering: turning a vague brief like "warm, editorial, honest" into a precise, consistent system of type, colour and spacing, then steering it conversationally until every page agreed with the others. The build itself ran through Claude Code, editing files directly and checking them in a live preview, with each change committed to Git and served, for free, from a GitHub Pages repository.

02What it's built on

Designed and built in conversation.

Claude (design)
The visual language, the warm paper background, the terracotta accent, the serif-and-mono pairing and the spacing rhythm, was shaped conversationally with Claude before a line of CSS was written.
Claude Code
Every page, the shared stylesheet and the interactive widgets were implemented with Claude Code, editing the files directly and verifying each change in a live browser preview.
Prompt engineering
The skill actually on show: describing intent precisely enough that the design stays consistent across pages, and steering edits with specific, unambiguous feedback rather than starting over.
GitHub Pages
The whole site is a static GitHub repository served straight from the main branch, so every commit is one push away from being live.
